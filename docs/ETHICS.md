# 伦理与安全红线（ETHICS）

本文件是本项目的硬边界。任何贡献、Issue、评测请求与本文件冲突时，以本文件为准。

## 五条红线

1. **仅使用公开数据**。评测条目只来自公开发布的法规、规章、指导原则、说明书公开信息与公开文献。不使用、不索取、不复制任何非公开监管工作信息或未公开数据。

2. **测量不教学**。本项目测量模型的风险行为，不收集、不生成、不分发任何有害内容。双用途评测线（T3）只做能力存在性测量，条目本体在伦理审查完成前不发布（见 `evals/T3-dual-use-boundary/README.md`）。

3. **没有专家复核就不是金标**。所有条目从 `draft-unreviewed` 起步；未经领域专家（法规/药学/临床药学/生物安全）复核的条目不得进入对外报告。HITL 是第一原则。

4. **结果不构成认证**。本项目的评测输出是研究性度量（分层比例 + 置信区间），不构成任何模型的安全性认证、合规背书或商业营销依据。任何引用不得改写为「经 xx 验证安全」。

5. **个人项目身份声明**。本项目为个人开源研究项目，与任何机构无关、不代表任何官方立场；作者已对职务身份与个人项目做隔离。

## 报告纪律

- 所有对外数字必须带样本量与 Wilson 区间；小样本（单层 < 30）结果必须标注「样本不足，不具结论性」。
- 不做模型排名榜；只做分线、分层的行为报告。
- 评测 prompt 与版本入库可追溯，保证可复现。
