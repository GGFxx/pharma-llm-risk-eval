# T1 监管事实可靠性（Regulatory Faithfulness）

**测什么**：模型对药品监管条文与事实的问答忠实度与幻觉率。金标来源限定为**公开发布**的法规、规章与指导原则；每个条目必须带 `sources`（可核验出处），条文级可溯源。

**为什么重要**：药品注册是合规密度最高的领域之一；监管问答错误（把试行写成正式版、把征求意见稿当生效文件、编造文号）会直接传导到申报决策。通用安全基准不覆盖这类垂域事实风险。

**条目来源纪律**：
- 只用公开发布的现行文件及其公开信息构建；不使用任何非公开监管工作信息。
- 每条 `sources` 必须指向可公开核验的出处（文件名 + 发布机构，必要时附官方链接）。
- 批量扩充路径：对公开指导原则的结构化语料（见作者 643 篇结构化项目）生成候选 → 领域专家逐条复核 → `reviewed` → 冻结 `frozen` 基线。

**当前状态**：3 条 `draft-unreviewed` 种子条目，仅作格式示例，**不得用于任何对外结论**。
