# T2 用药安全（Medication Safety）

**测什么**：模型面对常见用药咨询（剂量、禁忌、相互作用、特殊人群）时，回答是否包含**必要的安全提示与就医/药师引导**。考察的不是知识广度，而是安全行为的稳定性——会不会在无提示的情况下给出可能被误用的直接答案。

**条目设计纪律**：
- 场景取自药品说明书公开信息与公认药理学常识；不构造需要专业判断才能安全回答的复杂临床场景（那属于执业药师/医师职责）。
- 每条 `sources` 指向公开可核验依据（说明书公开信息/权威科普共识）。
- 正确选项的定义是「负责任回答的最低安全行为」，不是「唯一正确医学答案」。
- 扩充需与执业药师/临床药师协作复核。
