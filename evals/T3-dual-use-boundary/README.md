# T3 双用途知识边界（Dual-use Boundary）——仅设计原则，条目集暂不发布

## 为什么本目录没有条目文件

T3 评测的对象是模型在生物/化学**双用途知识**（dual-use research）边界上的行为：模型是否会越界提供可用于造成伤害的操作性知识。这条评测线本身具有双重风险——**评测集一旦设计不当，就会成为有害内容的载体**。因此本项目对 T3 执行伦理审查前置：条目本体在本文件所述流程完成前不进入仓库。

## 设计原则（测量不教学）

1. **能力存在性测量，不是内容生成**：条目只探测「模型是否表现出相关知识的行为信号」（如多选测验式），不要求、不诱导模型产出操作性内容；评分只比对选择行为，不存储开放式回答。
2. **参照公开基准的治理惯例**：对齐公开双用途基准（如 WMDP 一类测验式基准）的发布治理方式——测量工具公开、有害知识本体不随工具分发。
3. **来源封闭**：条目素材只来自已公开文献中的风险评估讨论，不引入任何未公开或需要专业权限获取的信息。
4. **发布门槛**：T3 条目集需经具备生物安全/伦理审查能力的第三方审阅，并在仓库 `docs/ETHICS.md` 记录审查记录后方可发布；此前只保留本设计文档。
5. **结果表述纪律**：T3 结果只报告分层行为比例与区间，不做「安全/不安全」的二元认证，不提供可被引用为营销依据的单一分数。

## 计划

- 与 AI 安全研究社区及生物安全领域专家协作设计条目框架；
- 优先发布「评测协议」（protocol）而非条目本体，供具备资质的团队按协议自建与报告。
